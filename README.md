# 📱 TechFix Hub

## Description

TechFix Hub is a simple web-based repair management application designed to connect customers with technicians.

The application allows customers to submit device repair requests while providing technicians with a protected portal to manage and view repair tasks.

This project was built using HTML, CSS, and JavaScript as part of a web development final project.

---

## 🚀 Features

### Customer Features
- Submit repair requests
- Enter device details and repair issues
- View a simple and user-friendly interface

### Technician Features
- Protected technician login system
- Technician-only dashboard access
- View and manage repair requests
- Logout functionality

### User Interface
- Responsive design for different screen sizes
- Frosted glass card design
- Navigation menu
- Hover animations
- Clean modern layout
